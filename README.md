# YT 歌詞（中文版）

在 YouTube 聽歌時，畫面右側會出現**跟著唱的同步歌詞**和**逐句翻譯**，還有**卡拉OK模式**和**影片字幕模式**。介面全部是繁體中文。

## ⬇️ [點這裡下載最新版](../../releases/latest/download/yt-lyrics-plus.zip)

下載後解壓縮，打開裡面的 `README-FIRST.txt`，照著步驟安裝（大約 2 分鐘）。
連結打不開的話（例如這個頁面沒有公開），請直接向分享給你的人索取 `YT-Lyrics-v版本.zip` 檔案。

## 這個外掛能做什麼

- **自動找歌詞**：分析影片標題與頻道名稱，自動到 LRCLIB、Lyrics.ovh 搜尋歌詞，也會使用影片本身上傳的 CC 字幕。
- **同步歌詞**：正在唱的那一句會亮起，唱過的會變淡；點任何一句就能跳到那個時間點。
- **自動捲動**：歌詞面板跟著播放進度捲動。自己用滑鼠捲動時會暫停幾秒，之後自動回到目前這一句。
- **逐句翻譯**：每句歌詞下方顯示譯文，預設繁體中文，也可以改成英文、日文、韓文等。
- **字幕時間微調**：歌詞太慢或太快時，按 + / − 一次調 0.2 秒（1～3 秒之間）。每部影片會分別記住。
- **卡拉OK模式**：全螢幕只留下 MV 和大字幕，正在唱的那一句會從左到右填色，下方附上翻譯和下一句。字幕顏色可以選預設配色或自訂，也可以關掉填色動畫。
- **影片字幕模式（CC）**：把目前這一句歌詞和翻譯顯示在影片中下方，字的大小跟著影片畫面自動縮放。
- **手動搜尋**：歌不對時按 🔍，輸入「歌手 - 歌名」重新搜尋。
- **自己做同步歌詞**：找不到歌詞時，按 ✎ 貼上歌詞，播放時每唱到一句按一下 Enter，就能做出會跟著亮起的歌詞；可以匯出成 .lrc 檔分享給朋友，朋友匯入後就能用。
- **調整大小**：拖曳面板左下角就能放大，字會跟著變大。
- **外觀**：多種面板主題、自訂顏色、背景透明度。
- **換歌不用重按**：面板開著時切到下一首，會自動找新歌的歌詞。

## 使用前需要準備什麼

- Windows、Mac 或 Linux 電腦
- Google Chrome 111 以上，或 Microsoft Edge、Brave 等以 Chromium 為核心的瀏覽器
- 網路連線（搜尋歌詞與翻譯需要連網）

## 怎麼開始使用

1. 下載 zip 檔，按右鍵選「解壓縮全部」，把解壓縮出來的 `YT-Lyrics` 資料夾放到一個不會刪掉的地方（例如「文件」）。
   - Chrome 會一直從這個資料夾讀取外掛，**資料夾移動、改名或刪除後外掛就會失效**。
2. 雙擊資料夾裡的 `open-install-page.bat`：它會打開 Chrome 的擴充功能頁，並把資料夾位置複製到剪貼簿（只做這兩件事，不會修改電腦設定）。
   - Windows 跳出藍色警告時，按「其他資訊」→「仍要執行」。
   - 不想執行它也可以：自己打開 Chrome，在網址列輸入 `chrome://extensions` 按 Enter。
3. 打開右上角的「**開發人員模式**」開關。
4. 按左上角的「**載入未封裝項目**」，在選擇資料夾視窗最上面的位址列按 `Ctrl+V` 貼上、按 Enter，再按「選擇資料夾」。
   - 沒有執行第 2 步的話，就自己找到 `YT-Lyrics` 資料夾，點一下再按「選擇資料夾」。
5. 清單中出現「YT 歌詞（中文版）」就完成了。建議按 Chrome 右上角的拼圖圖示，把它釘選在工具列上。
6. 打開 YouTube 播一首歌。如果歌詞沒有自動出現，按工具列上的外掛圖示 →「立即顯示歌詞」。

Microsoft Edge：網址列輸入 `edge://extensions`，打開左側的「開發人員模式」，按「載入解壓縮」。

### 歌詞面板上的按鈕

| 按鈕 | 功能 |
|---|---|
| − ±0 + | 字幕時間微調。字幕跟不上按 +（提早出現），太早出現按 −（延後出現）；每按一下調 0.2 秒，範圍 1～3 秒；點中間的數字歸零 |
| 🔍 | 歌不對時，輸入「歌手 - 歌名」重新搜尋（按 Enter 搜尋、Esc 收起） |
| ✎ | 製作／編輯這部影片的同步歌詞 |
| 🎤 | 進入／結束卡拉OK模式 |
| CC | 開關影片字幕模式（歌詞顯示在影片下方） |
| 譯 | 顯示／隱藏翻譯（按鈕變淡代表已關閉） |
| − | 縮小／展開面板 |
| × | 關閉面板 |

- 按住標題列的空白處可以拖曳移動面板。
- 拖曳面板**左下角**的斜線可以放大面板，字會跟著放大；在斜線上**按兩下**恢復預設大小。大小會自動記住。

### 卡拉OK模式

1. 播放歌曲並打開歌詞面板，確認是同步歌詞（歌詞會一句一句亮起）。
2. 按面板上的 🎤。畫面變成全螢幕，YouTube 的播放列和推薦影片都會隱藏，只剩 MV 和字幕。
3. 移動滑鼠時，左上角會出現字幕時間微調，右上角會出現「結束」按鈕；滑鼠停住 2.5 秒後自動隱藏。
4. 按 **Esc** 或右上角的「✕ 結束卡拉OK」離開。

卡拉OK模式中，YouTube 的鍵盤快捷鍵仍然可以用（例如空白鍵暫停）。播放清單切到下一首時會繼續維持卡拉OK模式。

### 影片字幕模式（CC）

按面板上的 **CC**，目前這一句歌詞和翻譯會顯示在影片中下方，外觀類似 YouTube 的 CC 字幕：

- 字的大小會跟著影片畫面大小自動調整（一般、劇院模式、全螢幕都適用）。
- 播放器的控制列出現時，字幕會自動往上讓開。
- 字幕大小（小／中／大）與顏色可以在設定視窗調整。
- 關閉歌詞面板或進入卡拉OK模式時，影片字幕會自動收起。

### 自己製作同步歌詞（打點）

適合資料庫找不到、或只有純文字歌詞的歌。

1. 按歌詞面板上的 ✎。
2. 把歌詞貼進輸入框，一行一句。手邊沒有歌詞的話，按「🔍 手動搜尋」會開新分頁用 Google 搜尋，找到後複製貼上。
3. 按「▶ 開始打點」，影片會從頭開始播放。
4. 每當新的一句**開始唱**時，按一下 **Enter**。按錯了按 **Backspace**，影片會倒回 3 秒讓你重打。按 **Esc** 取消。（按鍵可以在設定視窗更改）
5. 最後一句打完會自動儲存；也可以隨時按「完成並儲存」。

其他功能：

- 已經有 LRC 格式（每行開頭有 `[00:12.34]`）的歌詞，貼上後直接按「💾 儲存」。
- 「⬆ 匯出」把歌詞存成 .lrc 檔，可以傳給朋友；朋友在**同一部影片**按 ✎ →「匯入」→「💾 儲存」即可使用。
- 「🗑 刪除本機歌詞」刪除自己做的歌詞，改回自動搜尋。

自己做的歌詞和字幕時間微調，都是依「這部影片」儲存：同一首歌的其他影片（例如 Live 版）需要另外設定。

### 更新到新版

把新版 `YT-Lyrics` 資料夾裡的檔案，全部複製到原本的資料夾覆蓋（**資料夾位置不要變**），再到 `chrome://extensions` 按本外掛卡片上的「重新載入」（圓形箭頭）。設定和自己做的歌詞都會保留。

## 常見問題

**Chrome 每次啟動都跳出「停用開發人員模式擴充功能」的提示？**
這是 Chrome 對手動安裝外掛的固定提醒，按「×」關掉即可，**不要**按「停用」。「開發人員模式」要一直開著，關掉的話外掛會被停用。

**雙擊 `open-install-page.bat` 時 Windows 跳出警告？**
從網路下載的批次檔都會出現這個警告。按「其他資訊」→「仍要執行」即可；或不執行它，照「怎麼開始使用」第 2 步手動打開擴充功能頁。

**畫面上出現兩個歌詞面板？**
另外安裝了商店版的「YT Lyrics」，到 `chrome://extensions` 把它停用或移除。

**歌詞跟不上／太早出現？**
用面板左上角的 + / − 微調。每部影片會記住自己的微調。

**找不到歌詞或歌不對？**
按 🔍，輸入「歌手 - 歌名」再搜尋。有些歌在資料庫中只有純文字歌詞（不會跟著亮起），這時可以用 ✎ 自己打點製作。

**沒有翻譯？**
- 確認面板上的「譯」按鈕不是變淡的狀態。
- 翻譯需要連到 `translate.googleapis.com`，公司網路或 VPN 可能會擋住。
- 短時間內大量翻譯可能被 Google 暫時限制，稍後重新整理頁面再試。

**卡拉OK模式或 CC 字幕沒有出現？**
只有同步歌詞才能顯示。畫面顯示「這首歌沒有同步歌詞」時，代表資料庫只有純文字歌詞。

## 歌詞從哪裡來

- **本機歌詞**：你自己用 ✎ 製作或匯入的歌詞，永遠最優先。
- **LRCLIB**（`lrclib.net`）：主要來源，免費開放的同步歌詞資料庫。
- **Lyrics.ovh**（`api.lyrics.ovh`）：備用來源，只有純文字歌詞。
- **YouTube 影片字幕**：很多官方 MV 有上傳 CC 歌詞字幕，前面的來源找不到同步歌詞時使用。自動產生的字幕（語音辨識）對歌曲很不準，所以不採用。

搜尋順序：本機歌詞 → 快取 → LRCLIB／Lyrics.ovh 的同步歌詞 → YouTube 字幕 → 純文字歌詞。

## 注意事項

- **會傳到網路的資料**：
  - 歌名與歌手名稱會送到 LRCLIB 與 Lyrics.ovh 搜尋歌詞。
  - 開啟翻譯時，歌詞文字會送到 Google 翻譯（`translate.googleapis.com`）；關閉翻譯就不會送出。
  - 使用 YouTube 字幕時，只讀取 YouTube 本來就提供給這部影片的字幕。
  - 不會讀取或送出你的帳號、觀看紀錄或其他個人資料，也沒有任何使用數據追蹤。
- **儲存在電腦裡的資料**：外掛設定、歌詞快取、自己製作的歌詞、字幕時間微調與面板大小，都存在 Chrome 的外掛儲存空間，移除外掛時會一併刪除。
- **權限**：只在 `youtube.com` 執行，只會連線到上述網站；不需要系統管理員權限，也不會讀寫電腦上的其他檔案。
- 翻譯使用 Google 翻譯的公開網頁介面，並非正式服務，未來可能變更或限制。
- 本外掛以 Chrome 線上應用程式商店的「YouTube Lyrics Extension – Real-Time Synced Lyrics | YT Lyrics」為基礎修改而成，僅供個人與親友使用，請勿公開散布或上架。
