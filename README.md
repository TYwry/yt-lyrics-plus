# YT 歌詞（中文版）

在 YouTube 播放音樂時，於畫面右側顯示**即時同步歌詞**，歌詞會**自動捲動**到正在唱的那一句，並在每句下方顯示**翻譯**。介面全部是繁體中文。

## ⬇️ [點這裡下載最新版](../../releases/latest/download/yt-lyrics-plus.zip)

下載後解壓縮，再照下方「怎麼開始使用」的步驟載入 Chrome 即可。

> 本外掛是以 Chrome 線上應用程式商店的「YouTube Lyrics Extension – Real-Time Synced Lyrics | YT Lyrics」為基礎修改的個人版本，僅供個人使用，請勿散布。

---

## 這個外掛能做什麼

- **自動找歌詞**：分析影片標題與頻道名稱，自動到 LRCLIB、Lyrics.ovh 搜尋歌詞；找不到時可以手動輸入「歌手 - 歌名」。
- **同步歌詞**：正在唱的那一句會亮起，唱過的會變淡；點任何一句就能跳到那個時間點。
- **自動捲動**：歌詞面板會跟著播放進度捲動，讓目前這一句保持在中間。只捲動歌詞面板，不會拉動整個 YouTube 頁面。
- **手動捲動不打架**：用滑鼠滾輪或拖曳捲軸往前往後看時，自動捲動會暫停幾秒（可調整），之後自動回到目前這一句。點某一句歌詞跳轉時會立刻恢復。
- **逐句翻譯**：每句歌詞下方顯示譯文，預設為繁體中文，也可改成英文、日文、韓文等。歌詞面板標題列的「譯」按鈕可以隨時開關翻譯。
- **卡拉OK模式**：按歌詞面板上的 🎤，畫面切換成全螢幕，只留下 MV 和大字幕。正在唱的那一句會從左到右填色，下方附上翻譯和下一句。
- **換歌不用重按**：歌詞面板開著時切換到下一首（包含自動播放、播放清單），會自動找新歌的歌詞；卡拉OK模式也會持續顯示。
- **智慧自動顯示**：可以設定只在音樂影片自動打開歌詞面板。
- **縮小模式**：按「−」把面板縮小，只顯示目前這一句與前後句。
- **歌詞快取**：找到的歌詞會暫存在電腦裡，下次看同一部影片時直接載入。

## 使用前需要準備什麼

- Google Chrome，或 Microsoft Edge、Brave 等以 Chromium 為核心的瀏覽器
- 網路連線（搜尋歌詞與翻譯都需要連網）

## 怎麼開始使用

1. 下載上方的 `yt-lyrics-plus.zip`，按右鍵選「解壓縮全部」，放在一個不會刪掉的地方（例如 `文件\yt-lyrics-plus`）。
   - 載入後 Chrome 會一直從這個資料夾讀取檔案，**資料夾刪除或移動後外掛就會失效**。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
3. 打開右上角的「**開發人員模式**」開關。
4. 如果有安裝商店版的「YT Lyrics」，請先把它**停用**，否則畫面上會同時出現兩個歌詞面板。
5. 按左上角的「**載入未封裝項目**」，選擇剛剛解壓縮出來、裡面有 `manifest.json` 的資料夾。
6. 清單中出現「YT 歌詞（中文版）」就代表安裝完成。
7. 重新整理 YouTube 頁面並播放一首歌。如果歌詞面板沒有自動出現，按 Chrome 右上角的拼圖圖示 →「YT 歌詞（中文版）」→「立即顯示歌詞」。

### 歌詞面板上的按鈕

| 按鈕 | 功能 |
|---|---|
| 🎤 | 進入／結束卡拉OK模式 |
| 譯 | 顯示／隱藏翻譯（按鈕變淡代表翻譯已關閉） |
| − | 縮小／展開面板 |
| ↻ | 不使用快取，重新搜尋歌詞 |
| × | 關閉面板 |

按住面板標題列可以拖曳移動位置。

### 卡拉OK模式

1. 播放歌曲並打開歌詞面板，確認歌詞是「同步歌詞」（面板上有「⚡ 同步歌詞」字樣）。
2. 按面板標題列的 🎤。畫面會變成全螢幕，YouTube 的播放列、按鈕、推薦影片都會隱藏，只剩 MV 和字幕。
3. 滑鼠停止移動 2.5 秒後，游標和右上角的「結束」按鈕會自動隱藏；移動滑鼠就會出現。
4. 按 **Esc** 或右上角的「✕ 結束卡拉OK」離開。

在卡拉OK模式中，YouTube 的鍵盤快捷鍵仍然可以用，例如空白鍵暫停、左右方向鍵快轉倒轉。播放清單切到下一首時會繼續維持卡拉OK模式。

### 設定視窗

按 Chrome 右上角的拼圖圖示，點「YT 歌詞（中文版）」：

| 設定 | 說明 |
|---|---|
| 自動顯示歌詞 | 所有影片都自動打開歌詞面板 |
| 智慧自動顯示 | 只在音樂影片自動打開（推薦） |
| 深色模式 | 歌詞面板與設定視窗使用深色主題；旁邊的 🔄 可以重新載入外掛 |
| 自動捲動歌詞 | 開啟／關閉自動捲動 |
| 手動捲動後暫停 | 自己捲動後，幾秒後恢復自動捲動（0～60 秒） |
| 顯示翻譯 | 開啟／關閉翻譯 |
| 翻譯成 | 選擇翻譯的目標語言 |
| 立即顯示歌詞 | 在目前的 YouTube 影片打開歌詞面板 |

捲動與翻譯的設定會立即套用，不必重新整理頁面。

### 更新到新版

下載新版 zip，解壓縮後覆蓋原本資料夾裡的檔案，再到 `chrome://extensions` 按本外掛卡片上的「重新載入」（圓形箭頭）按鈕。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `manifest.json` | 外掛的基本設定（名稱、權限、要載入哪些檔案） |
| `content.js` | 在 YouTube 頁面執行：辨識歌曲、搜尋歌詞、顯示面板、同步、自動捲動、翻譯 |
| `background.js` | 在背景執行：安裝時寫入預設設定，並向 Google 翻譯送出翻譯請求 |
| `popup.html`、`popup.js` | 點外掛圖示時出現的設定視窗 |
| `locales.js` | 設定視窗的中文文字 |
| `icon16.png`、`icon48.png`、`icon128.png` | 外掛圖示 |
| `setup-github.bat`、`save.bat`、`publish-release.bat` | 維護原始碼用的腳本，一般使用者不需要 |

## 常見問題

**Chrome 每次啟動都跳出「停用開發人員模式擴充功能」的提示？**
這是 Chrome 對所有手動載入外掛的標準提醒，按「×」關掉即可，**不要**按「停用」。

**畫面上出現兩個歌詞面板？**
商店版的 YT Lyrics 還開著。到 `chrome://extensions` 把它停用或移除。

**找不到歌詞？**
在面板的搜尋框輸入「歌手 - 歌名」（例如 `歌手名稱 - 歌曲名稱`）再按搜尋。部分歌曲在歌詞資料庫中沒有同步歌詞，只會顯示純文字歌詞，此時不會自動捲動。

**沒有翻譯？**
- 確認面板標題列的「譯」按鈕不是變淡的狀態，或到設定視窗確認「顯示翻譯」已開啟。
- 翻譯需要連到 `translate.googleapis.com`；公司網路或 VPN 可能擋住。
- 短時間內大量翻譯可能被 Google 暫時限制，稍後重新整理頁面再試。

**卡拉OK模式沒有字幕？**
只有同步歌詞才能顯示卡拉OK字幕。畫面上出現「這首歌沒有同步歌詞」時，代表歌詞資料庫只有純文字歌詞。

**自動捲動沒有動？**
- 確認設定視窗的「自動捲動歌詞」已開啟。
- 剛手動捲動過的話，要等暫停秒數過後才會恢復。
- 只有「同步歌詞」才會自動捲動；純文字歌詞沒有時間資訊。

## 注意事項

- **會傳到網路的資料**：
  - 歌曲名稱與歌手名稱會送到歌詞資料庫 LRCLIB（`lrclib.net`）與 Lyrics.ovh（`api.lyrics.ovh`）搜尋歌詞。
  - 開啟翻譯時，歌詞文字會送到 Google 翻譯（`translate.googleapis.com`）。關閉翻譯就不會送出。
  - 不會送出你的 Google 帳號、觀看紀錄或其他個人資料，也沒有任何使用數據追蹤。
- **儲存在電腦裡的資料**：外掛設定，以及最多 200 首歌的歌詞快取，都存在 Chrome 的外掛儲存空間。移除外掛時會一併刪除。
- **權限**：只在 `youtube.com` 頁面執行；另外只會連線到上述三個網站。
- 翻譯使用 Google 翻譯的公開網頁介面，並非正式付費服務，Google 未來可能變更或限制。
