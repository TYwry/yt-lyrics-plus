YT 歌詞（中文版）安裝說明
==========================

這是一個 Chrome 外掛：在 YouTube 聽歌時，右邊會出現會跟著唱的歌詞、翻譯，還有卡拉OK模式。
安裝大約 2 分鐘，只要做一次。


【安裝步驟】

1. 放好資料夾
   把這個「YT-Lyrics」資料夾放到一個不會刪掉的地方，例如「文件」。
   ※ 裝好之後不要移動、改名或刪除這個資料夾，否則外掛會失效。

2. 雙擊資料夾裡的「open-install-page.bat」
   它會打開 Chrome 的「擴充功能」頁面，並自動把這個資料夾的位置複製好。
   ※ 如果 Windows 跳出藍色警告，按「其他資訊」→「仍要執行」。
   ※ 如果沒有打開 Chrome：自己打開 Chrome，在網址列輸入 chrome://extensions 按 Enter。

3. 打開右上角的「開發人員模式」開關。

4. 按左上角的「載入未封裝項目」。
   在跳出來的選擇資料夾視窗，點最上面的位址列，按 Ctrl+V 貼上，按 Enter，
   再按右下角的「選擇資料夾」。
   （沒有執行第 2 步的話，就自己找到這個 YT-Lyrics 資料夾，點一下它，再按「選擇資料夾」。）

5. 看到「YT 歌詞（中文版）」出現在清單裡就完成了。
   建議按 Chrome 右上角的拼圖圖示，把「YT 歌詞（中文版）」旁邊的圖釘點起來，之後比較好找。

6. 打開 YouTube 播一首歌，按 Chrome 右上角的外掛圖示，歌詞就會出現。
   （歌詞不會自己跳出來。播音樂影片時右上角會出現一顆小圓點，點它也能打開歌詞；
     小圓點按右鍵可以關掉。面板開著時換下一首會自動換歌詞。）


【怎麼用】

歌詞面板上面那一排按鈕：
  −  +    字幕時間微調：字幕跟不上時按 +（提早），太早出現按 −（延後），點中間的數字歸零
  0.2s▾   每按一次 + / − 調幾秒（0.2～10 秒），差很多時選大一點
  🔍      歌不對時，自己輸入「歌手 - 歌名」搜尋
  ✎       自己製作同步歌詞（貼上歌詞，播放時每句開始唱時按住 Enter、唱完放開，打完自動儲存）
  🎤      卡拉OK模式（全螢幕，只顯示影片和大字幕，按 Esc 離開）
  CC      把歌詞像字幕一樣顯示在影片下方
  譯      開關翻譯
  ●       縮成一個小圓點（圓點可以拖曳，點一下就展開成完整歌詞）
  −       折疊面板（折疊後變成 ⤢，再按一次展開；在面板上按右鍵也可以）
  ×       關閉面板
找不到歌詞時，可以按「🔄 重新自動搜尋」再找一次。
面板左下角可以拖曳放大，字會跟著變大；按標題列空白處可以拖曳移動位置。
更多設定（主題顏色、卡拉OK字幕顏色、翻譯語言等）：按 Chrome 右上角的外掛圖示。


【歌詞庫：自己做的歌詞、朋友分享的歌詞】

按 Chrome 右上角的外掛圖示 →「我的歌詞庫」旁邊的「📚 打開」。
  - 可以看到所有自己做的、朋友分享的同步歌詞，能搜尋、改歌名、刪除、直接開啟影片。
  - 朋友傳來 yt-lyrics-library-日期.json 檔案時：按「📂 匯入」選這個檔案就好（也可以直接把檔案拖進頁面）。
    重複匯入沒關係，已經有的歌會自動略過；你自己做的歌不會被覆蓋。
  - 想分享給朋友：按「⬆ 全部匯出」，把下載的 .json 檔傳給他。
  - 同一首歌的不同影片（例如 MV 和官方音訊版）也會自動套用，時間對不上時用 + / − 微調。
  - 如果這份安裝包裡已經附了歌詞，安裝完就會自動出現在歌詞庫裡。


【常見問題】

Q：每次打開 Chrome 都跳出「停用開發人員模式擴充功能」？
A：這是 Chrome 對自己安裝的外掛的固定提醒，按「×」關掉就好，不要按「停用」。
   「開發人員模式」要一直開著，關掉的話這個外掛會被停用。

Q：用的是 Microsoft Edge？
A：一樣可以用。網址列輸入 edge://extensions，打開左邊的「開發人員模式」，
   按「載入解壓縮」，選這個資料夾即可。

Q：畫面上出現兩個歌詞面板？
A：你另外裝了商店版的「YT Lyrics」，到擴充功能頁把它關掉。

Q：怎麼更新到新版？
A：把新版資料夾裡的檔案，全部複製到原本的 YT-Lyrics 資料夾覆蓋（資料夾位置不要變），
   再到擴充功能頁按這個外掛卡片上的「重新載入」（圓形箭頭）。你的設定和歌詞庫都會保留；
   新版安裝包附的歌詞也會自動加進歌詞庫。


【隱私】

- 歌名和歌手會送到歌詞資料庫 lrclib.net、lyrics.ovh 搜尋歌詞。
- 開著翻譯時，歌詞文字會送到 Google 翻譯。
- 不會讀取或送出你的帳號、觀看紀錄等個人資料，也沒有任何追蹤。
